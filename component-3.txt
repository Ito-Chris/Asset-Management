## 🔐 Privacy & Security Notes

- **No data leaves the browser.** There is no backend, no telemetry, and no external API calls.
- Asset data is held in React state only — refreshing the page resets the register.
- The "AI Translation" feature uses a bundled offline dictionary, so it works fully air-gapped.
