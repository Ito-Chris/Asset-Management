# ISMS K9 Security Management

An ISO/IEC 27001-aligned security asset register. Track security assets, their
classification, criticality, mapped controls, and compliance state — all in the
browser with no backend.

## Features

- **Asset register** — endpoints, network gear, identity providers, data stores,
  and physical assets with tags, owners, and locations.
- **Compliance tracking** — each asset carries a status (Compliant / Review /
  At risk) that can be advanced with one click.
- **Control mapping** — assets reference ISO/IEC 27001 Annex A controls.
- **Live filtering** — search by name, tag, or owner, plus category and status
  filters.
- **Dashboard stats** — compliant / review / at-risk / critical counts.

## Tech stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui components
- lucide-react icons
